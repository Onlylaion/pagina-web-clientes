Lo que ya construimos

Un sistema para una florería real.
Así quedó.

Las Flores Laferrere es un negocio de venta de cotillón y souvenirs que gestionaba decenas de pedidos por semana —souvenirs de 15 años, casamientos, bautismos y cumpleaños— con cuadernos y planillas de Excel. El stock se llevaba a mano, las señas para reservar pedidos se anotaban en papel y a fin de mes había que juntar todo para saber cuánto habían ganado.

Construimos para ellos un sistema completo que centraliza todo: cada pedido tiene su estado y fecha de entrega, cada pago queda registrado con su saldo, el stock se actualiza automáticamente con cada venta y el dueño puede ver cómo va el negocio desde el celular en cualquier momento.

Este es el sistema en funcionamiento. No es un ejemplo ni una demo armada para mostrar — es lo que usamos como base para construir el tuyo.
